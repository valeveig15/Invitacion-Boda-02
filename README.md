# Invitación botánica · Martina & Federico · V2

Versión reconstruida tomando como referencia la lógica de animaciones de la invitación fotográfica, pero conservando la identidad botánica: paleta salvia/verde, tipografía propia, nombres, fecha, ubicaciones y acuarelas originales.

## Incluye
- `index.html`
- `style.css`
- `script.js`
- `assets/botanical/` con todas las hojas y fondos
- `assets/audio/wedding-music.mp3`
- `assets/textures/paper.jpg`
- `.nojekyll`

## Cambios principales
- Hojas visibles como fondo real de portada, escritorio y celular.
- Tipografía ampliada en toda la invitación.
- Capilla vectorial correcta, animada con halo y respiración suave.
- Copas flauta animadas con choque, corazón y destello.
- Galería sin números y con lightbox.
- Caja de regalo animada con apertura lateral y destellos.
- Instagram de la pareja con logo y aura animada.
- Dress code con percha/vestido animados.
- Info útil con pin y destellos animados.
- Música con icono flotante y desbloqueo automático tras la primera interacción si el navegador bloquea autoplay.
- RSVP, mapas, calendario y sugerencia de canciones.
- Se eliminó el bloque final de agradecimiento.
- `artedeco.studio` aparece en tamaño protagonista al final.

## GitHub Pages
Subí todo el contenido de esta carpeta a la raíz del repositorio. Luego: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Personalización
Los datos de muestra se editan directamente en `index.html`. Los datos bancarios de demo están en `script.js`.
